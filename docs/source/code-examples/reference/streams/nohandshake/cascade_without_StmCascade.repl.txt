> // Equivalent output can be produced with less overhead.
> // In the value below, the undefined elements above have
> // been replaced by concrete values, but that's fine.
> // StmExtendBy(2) is free; it just changes the stream length.
> // StmMap(v => VecCst(3, v[0])) is also basically free;
> // it simply increases the fanout of v[0].
> // All that remains is StmSlide(3).
> // TOTAL COST: 2 registers (each with 8 bits)
