Booleans#

Sirop has booleans and boolean operators like most other programming languages.

Logical Operators#

&& performs logical AND.

> (false && false, false && true, true && false, true && true)
(false, false, false, true)

|| performs logical OR.

> (false || false, false || true, true || false, true || true)
(false, true, true, true)

! performs logical NOT.

> (!false, !true)
(true, false)

Unlike other operators, logical operators can sometimes produce a concrete value even with one of the operands being undefined. This makes them a bit like the short-circuiting logical operators in other languages. However, unlike in other languages, the order does not matter. (In hardware, both branches are evaluated simultaneously.)

> u = undefined:bool
>
> (u && false, false && u, u && true, true && u)
(false, false, undefined:bool, undefined:bool)
> (u || false, false || u, u || true, true || u)
(undefined:bool, undefined:bool, true, true)
>
> // This is a bit like short-circuiting, except order doesn't matter
> x = 1:u8
> y = 0:u8
> x % y == 0 // division by zero :(
undefined:bool
> y == 0 || x % y == 0
true
> x % y == 0 || y == 0
true
>
> // not(undefined) is still undefined though
> (!u)
undefined:bool

Relational Operators#

== evaluates to true if and only if its operands have the same value. != is its inverse. <, <=, >, and >= have their usual mathematical meaning.

> // (==) Equals
> ([42:u8, 43:u8]v, true) == ([42:u8, 43:u8]v, true)
true
> ([42:u8, 43:u8]v, true) == ([42:u8, 43:u8]v, false)
false
> ([42:u8, 43:u8]v, true) == ([42:u8,  0:u8]v, true)
false
>
> // (!=) Not equal
> ([42:u8, 43:u8]v, true) != ([42:u8, 43:u8]v, true)
false
> ([42:u8, 43:u8]v, true) != ([42:u8, 43:u8]v, false)
true
> ([42:u8, 43:u8]v, true) != ([42:u8,  0:u8]v, true)
true
>
> // (<) Strictly less than
> (41 < 42, 42 < 42, 43 < 42)
(true, false, false)
>
> // (<=) Less than or equal
> (41 <= 42, 42 <= 42, 43 <= 42)
(true, true, false)
>
> // (>) Strictly greater than
> (41 > 42, 42 > 42, 43 > 42)
(false, false, true)
>
> // (>=) Greater than or equal
> (41 >= 42, 42 >= 42, 43 >= 42)
(false, true, true)
