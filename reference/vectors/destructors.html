Reading a Vector#

Simple Vector Accesses#

The notation v[i] is used to access the element at index i in vector v. The indices in a vector start at 0. For example:

> my_vec = [42:u8, 43:u8, 44:u8, 45:u8]v
>
> my_vec[0]
42:u8
> my_vec[1]
43:u8
> my_vec[2]
44:u8
> my_vec[3]
45:u8

The index must be an unsigned integer.

> my_vec = [42:u8, 43:u8, 44:u8, 45:u8]v
>
> my_vec[-1]
TypeError: Expected an unsigned integer but found i1.

Out-of-bounds vector accesses evaluate to undefined.

> my_vec = [42:u8, 43:u8, 44:u8, 45:u8]v
>
> my_vec[4]
undefined:u8
> my_vec[999]
undefined:u8

Vector Slicing#

The notation vec[start:len:step] produces a “slice” of vector vec. start is the first index to read, len is the number of elements to read, and step is the difference between consecutive indices. In other words, vec[start:len:step] produces [ vec[start], vec[start + step], vec[start + 2*step], ..., vec[start + (len - 1)*step] ]v. For example:

> my_vec = [42:u8, 43:u8, 44:u8, 45:u8, 46:u8, 47:u8, 48:u8]v
>
> // Starting at index 1, read 3 elements, taking every 2nd element
> my_vec[1:3:2]
[43:u8, 45:u8, 47:u8]v
> // Equivalently...
> [ my_vec[1], my_vec[3], my_vec[5] ]v
[43:u8, 45:u8, 47:u8]v
>
> // The step can be negative!
> // Starting at index 3, take 4 elements, reading backwards
> my_vec[3:4:-1]
[45:u8, 44:u8, 43:u8, 42:u8]v

As with simple vector accesses, out-of-bounds elements will be undefined.

> my_vec = [42:u8, 43:u8, 44:u8, 45:u8, 46:u8, 47:u8, 48:u8]v
>
> my_vec[5:4:1]
[47:u8, 48:u8, undefined:u8, undefined:u8]v
> my_vec[1:3:-1]
[43:u8, 42:u8, undefined:u8]v
> my_vec[-1:3:1]
[undefined:u8, 42:u8, 43:u8]v

Any of the three values can be omitted. If the step is omitted, it defaults to 1.

> my_vec = [42:u8, 43:u8, 44:u8, 45:u8, 46:u8, 47:u8, 48:u8]v
>
> my_vec[0:3:]
[42:u8, 43:u8, 44:u8]v
> my_vec[1:3:]
[43:u8, 44:u8, 45:u8]v
> my_vec[2:3:]
[44:u8, 45:u8, 46:u8]v

If the start is omitted, its default is chosen as follows:

  • When step < 0: the default start is the last index.

  • When step >= 0: the default start is 0.

> my_vec = [42:u8, 43:u8, 44:u8, 45:u8, 46:u8, 47:u8, 48:u8]v
>
> my_vec[:4:2] // default start: 0
[42:u8, 44:u8, 46:u8, 48:u8]v
> my_vec[:4:-2] // default start: 6 (last index)
[48:u8, 46:u8, 44:u8, 42:u8]v
> my_vec[:4:] // default step: 1, default start: 0
[42:u8, 43:u8, 44:u8, 45:u8]v

If the len is omitted, its value will be chosen to maximize the length of the slice while avoiding out-of-bounds accesses. In other words, the slice will continue all the way to the end of the vector (or all the way to the start, when step < 0).

> my_vec = [42:u8, 43:u8, 44:u8, 45:u8, 46:u8, 47:u8, 48:u8]v
>
> my_vec[2::2] // default len: 3
[44:u8, 46:u8, 48:u8]v
> my_vec[3::2] // default len: 2
[45:u8, 47:u8]v
> my_vec[4::] // default step: 1, default len: 3
[46:u8, 47:u8, 48:u8]v
> my_vec[::-1] // default start: 7, default len: 7
[48:u8, 47:u8, 46:u8, 45:u8, 44:u8, 43:u8, 42:u8]v
> my_vec[::] // default step: 1, default start: 0, default len: 7
[42:u8, 43:u8, 44:u8, 45:u8, 46:u8, 47:u8, 48:u8]v

Warning

The len cannot be omitted when step = 0.
