Binary Conversion

Binary Conversion#

Sirop provides built-in functions for converting a value to its binary representation and back.

bits(x: T): Vec[bool, n], where n is the bitwidth for type T#

Produces the binary representation of x.

> ([5:u4, 8:u4]v, true).bits() // ([0b0101, 0b1000]v, 1)
[false, true, false, true, true, false, false, false, true]v

See also

interpret_as, for converting the binary representation back to some type.

interpret_as:[T](x: Vec[bool, n]): T, where T has bitwidth n#

Converts a boolean vector x to the given type.

> binary = [false, true, false, true, true, false, false, false, true]v
> binary.interpret_as:[(Vec[u4, 2], bool)]()
([5:u4, 8:u4]v, true)
> binary.interpret_as:[u9]()
177:u9

Warning

The target type T must have bitwidth n.

> binary = [false, true, false, true, true, false, false, false, true]v
> binary.interpret_as:[u8]()
TypeError: Bitwidths in InterpretAs do not match: input is 9:u4 bits wide but the target type is 8:u4 bits wide.
> binary.interpret_as:[u10]()
TypeError: Bitwidths in InterpretAs do not match: input is 9:u4 bits wide but the target type is 10:u4 bits wide.

See also

bits, for getting the binary representation
