Vectors#

As described in Overview, a vector is a combinational collection. Elements of a vector can be accessed all at once, in the same clock cycle.

Built-In Vector Functions#

The following vector operators are provided as part of the Sirop language.

Creating Vectors#

VecCst(n: I, k: T): Vec[T, n], where I is an unsigned integer type#

Creates a vector of length n whose elements are all the constant k.

> VecCst(3, (42:u8, true))
[(42:u8, true), (42:u8, true), (42:u8, true)]v
VecCount(n: I, init: J, delta: J): Vec[J, n], where I is an unsigned integer type and J is any integer type#

Creates a vector of n integers starting at init and increasing by delta.

> VecCount(5:u3)
[0:u3, 1:u3, 2:u3, 3:u3, 4:u3]v
> VecCount(4, 42:u32)
[42:u32, 43:u32, 44:u32, 45:u32]v
> VecCount(3, -9:i8, -2:i8)
[-9:i8, -11:i8, -13:i8]v

Transforming Vectors Elementwise#

VecMap(v: Vec[A, n], f: A -> B): Vec[B, n]#

Applies function f elementwise to vector v.

> [1:u8, 2:u8, 3:u8, 4:u8]v.VecMap(x => x + 5)
[6:u8, 7:u8, 8:u8, 9:u8]v

Combining Multiple Vectors#

VecConcat(v1: Vec[T, n], v2: Vec[T, m]): Vec[T, n+m]#

Concatenates two vectors.

> [1:u8, 2:u8, 3:u8]v.VecConcat([8:u8, 7:u8]v)
[1:u8, 2:u8, 3:u8, 8:u8, 7:u8]v
VecZip(v1: Vec[A, n], v2: Vec[B, n]): Vec[(A, B), n]#

Pairs up the elements of two vectors.

> u = [ 1:u6,  2:u6,  3:u6]v
> v = [-9:i8, -8:i8, -7:i8]v
> VecZip(u, v)
[(1:u6, -9:i8), (2:u6, -8:i8), (3:u6, -7:i8)]v

See also

VecMap2, which zips two vectors with an arbitrary function

VecMap2(v1: Vec[A, n], v2: Vec[B, n], f: A -> B -> C): Vec[C, n]#

Like VecMap, but for two streams at once.

> u = [ 1:u6,  2:u6,  3:u6]v
> v = [-9:i8, -8:i8, -7:i8]v
> VecMap2(u, v, x => y => (x, y, x*y))
[(1:u6, -9:i8, -9:i8), (2:u6, -8:i8, -16:i8), (3:u6, -7:i8, -21:i8)]v

See also

VecZip, the special case where f is simply x => y => (x, y)

Aggregation#

VecAll(v: Vec[bool, n]): bool#

Returns true if all elements of vector v are true.

> [true, true, true]v.VecAll()
true
> [true, true, false]v.VecAll()
false
> [true, false, true]v.VecAll()
false
> [false, true, true]v.VecAll()
false
> [false, false, false]v.VecAll()
false

When applied to an empty vector, VecAll returns true.

> ([]v:Vec[bool,0]).VecAll()
true

See also

VecFold, for aggregation with an arbitrary function

VecAny(v: Vec[bool, n]): bool#

Returns true if any elements of vector v are true.

> [false, false, false]v.VecAny()
false
> [false, false, true]v.VecAny()
true
> [false, true, false]v.VecAny()
true
> [true, false, false]v.VecAny()
true
> [true, true, true]v.VecAny()
true

When applied to an empty vector, VecAny returns false.

> ([]v:Vec[bool,0]).VecAny()
false

See also

VecFold, for aggregation with an arbitrary function

VecSum(v: Vec[I, n]): I, where I is an integer type#

Returns the sum of the elements in vector v.

> [1:u8, 2:u8, 3:u8, 4:u8]v.VecSum()
10:u8
> [-9:i16, -8:i16, -7:i16]v.VecSum()
-24:i16

When applied to an empty vector, VecSum returns 0.

> ([]v:Vec[u2,0]).VecSum()
0:u2

Warning

Beware of overflow! The sum is performed with the same type as the inputs.

> [255:u8, 1:u8]v.VecSum()
0:u8
> [255:u8, 1:u8]v.VecMap(x => pad9(x)).VecSum()
256:u9

See also

VecFold, for aggregation with an arbitrary function

VecFold(v: Vec[A, n], z: B, f: (B, A) -> B): B#

Combines the elements in vector v to a single value using function f and initial value z.

For example, for a 3-element stream [a, b, c]v, the result will be f(f(f(z, a), b), c).

> [1:i8, 2:i8, 8:i8]v.VecFold(9:i8, @(x, y) => x - y) // 9 - 1 - 2 - 8
-2:i8
> [2:u16, 0:u16, 2:u16, 6:u16]v.VecFold(0:u16, @(x, y) => 10*x + y)
2026:u16

Unlike with VecReduce, the input vector can be empty.

> ([]v:Vec[u8,0]).VecFold(42:u8, @(x, y) => x + y)
42:u8

See also

VecAll, the special case of VecFold with logical AND

VecAny, the special case of VecFold with logical OR

VecSum, the special case of VecFold with addition

VecReduce, for aggregation of a non-empty vector without needing to specify an initial value

VecReduce(v: Vec[T, n], f: (T, T) -> T): Vec[T, 1]#

Combines the elements in vector v to a single value using function f.

For example, for a 3-element vector [a, b, c]v, the result will be f(f(a, b), c).

> [4:u8, 9:u8, 1:u8, 3:u8]v.VecReduce(@(x, y) => min(x, y))
1:u8
> [4:u8, 9:u8, 1:u8, 3:u8]v.VecReduce(@(x, y) => max(x, y))
9:u8
> [4:i8, 9:i8, 1:i8, 3:i8]v.VecReduce(@(x, y) => x - y) // 4 - 9 - 1 - 3
-9:i8

Warning

The input vector must be non-empty.

> ([]v:Vec[u8,0]).VecReduce(@(x, y) => x + y)
undefined:u8

See also

VecFold, for aggregation of a possibly empty vector with a given initial value

Nested Vectors#

VecJoin(v: Vec[Vec[T, m], n]): Vec[T, n*m]#

Removes the outermost level of nesting from vector v.

> // 2 dimensions
> [[1:u8, 2:u8, 3:u8]v, [4:u8, 5:u8, 6:u8]v]v.VecJoin()
[1:u8, 2:u8, 3:u8, 4:u8, 5:u8, 6:u8]v
>
> // 3 dimensions
> [[[1:u8, 2:u8]v, [3:u8, 4:u8]v]v, [[5:u8, 6:u8]v, [7:u8, 8:u8]v]v]v.VecJoin()
[[1:u8, 2:u8]v, [3:u8, 4:u8]v, [5:u8, 6:u8]v, [7:u8, 8:u8]v]v
> [[[1:u8, 2:u8]v, [3:u8, 4:u8]v]v, [[5:u8, 6:u8]v, [7:u8, 8:u8]v]v]v.VecMap(v => v.VecJoin())
[[1:u8, 2:u8, 3:u8, 4:u8]v, [5:u8, 6:u8, 7:u8, 8:u8]v]v

See also

VecSplit, for converting a flat vector back to a nested vector

VecSplit(v: Vec[T, n], m: I): Vec[Vec[T, m], n/m]#

Increases the level of nesting of vector v.

> // 2 dimensions
> [1:u8, 2:u8, 3:u8, 4:u8, 5:u8, 6:u8]v.VecSplit(2)
[[1:u8, 2:u8]v, [3:u8, 4:u8]v, [5:u8, 6:u8]v]v
> [1:u8, 2:u8, 3:u8, 4:u8, 5:u8, 6:u8]v.VecSplit(3)
[[1:u8, 2:u8, 3:u8]v, [4:u8, 5:u8, 6:u8]v]v
> [1:u8, 2:u8, 3:u8, 4:u8, 5:u8, 6:u8]v.VecSplit(6)
[[1:u8, 2:u8, 3:u8, 4:u8, 5:u8, 6:u8]v]v
>
> // 3 dimensions
> [1:u8, 2:u8, 3:u8, 4:u8, 5:u8, 6:u8, 7:u8, 8:u8]v.VecSplit(2).VecSplit(2)
[[[1:u8, 2:u8]v, [3:u8, 4:u8]v]v, [[5:u8, 6:u8]v, [7:u8, 8:u8]v]v]v

Warning

If m does not divide n, some elements will be discarded.

> [1:u8, 2:u8, 3:u8, 4:u8, 5:u8, 6:u8, 7:u8]v.VecSplit(2)
[[1:u8, 2:u8]v, [3:u8, 4:u8]v, [5:u8, 6:u8]v]v

See also

VecJoin, for converting a nested vector back to a flat vector

Reordering Vectors#

VecShiftLeft(v: Vec[T, n], input: T): Vec[T, n]#

Shifts vector v left and inserts input at the end.

> [1:u8, 2:u8, 3:u8, 4:u8]v.VecShiftLeft(42:u8)
[2:u8, 3:u8, 4:u8, 42:u8]v

If v is empty, input is unused.

> ([]v:Vec[u8,0]).VecShiftLeft(42:u8)
[]v:Vec[u8, 0]
VecReverse(v: Vec[T, n]): Vec[T, n]#

Reverses vector v.

> [1:u8, 2:u8, 3:u8, 4:u8]v.VecReverse()
[4:u8, 3:u8, 2:u8, 1:u8]v
>
> [[1:u8, 2:u8]v, [3:u8, 4:u8]v]v.VecReverse()
[[3:u8, 4:u8]v, [1:u8, 2:u8]v]v
VecTranspose(v: Vec[Vec[T, m], n]): Vec[Vec[T, n], m]#

Transposes vector v.

> [[1:u8, 2:u8]v, [3:u8, 4:u8]v, [5:u8, 6:u8]v]v.VecTranspose()
[[1:u8, 3:u8, 5:u8]v, [2:u8, 4:u8, 6:u8]v]v

Discarding Parts of a Vector#

VecDrop(v: Vec[T, n], k: I): Vec[T, n-k], where I is an integer type#

Discards the first k elements from vector v.

> [1:u8, 2:u8, 3:u8, 4:u8]v.VecDrop(2)
[3:u8, 4:u8]v
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecDrop(1)
[2:u8, 3:u8, 4:u8]v
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecDrop(0)
[1:u8, 2:u8, 3:u8, 4:u8]v
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecDrop(4)
[]v:Vec[u8, 0]

Warning

It is an error to drop more than the available number of elements.

> [1:u8, 2:u8, 3:u8, 4:u8]v.VecDrop(5)
undefined:Vec[u8, undefined:u3]
> 4:u3 - 5:u3 // Output length is 4:u3 - 5:u3, which is undefined
undefined:u3

See also

VecTakeRight, if it is easier to say how many elements to keep than to say how many to discard

VecDropRight, for discarding elements from the end of a vector

VecTake, for discarding elements from the end of a vector

VecDropRight(v: Vec[T, n], k: I): Vec[T, n-k], where I is an unsigned integer type#

Discards the last k elements from vector v.

> [1:u8, 2:u8, 3:u8, 4:u8]v.VecDropRight(2)
[1:u8, 2:u8]v
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecDropRight(1)
[1:u8, 2:u8, 3:u8]v
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecDropRight(0)
[1:u8, 2:u8, 3:u8, 4:u8]v
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecDropRight(4)
[]v:Vec[u8, 0]

Warning

It is an error to drop more than the available number of elements.

> [1:u8, 2:u8, 3:u8, 4:u8]v.VecDropRight(5)
undefined:Vec[u8, undefined:u3]
> 4:u3 - 5:u3 // Output length is 4:u3 - 5:u3, which is undefined
undefined:u3

See also

VecTake, if it is easier to say how many elements to keep than to say how many to discard

VecDrop, for discarding elements from the beginning of a vector

VecTakeRight, for discarding elements from the beginning of a vector

VecTake(v: Vec[T, n], k: I): Vec[T, k], where I is an unsigned integer type#

Returns the first k elements of vector v, discarding the rest.

> [1:u8, 2:u8, 3:u8, 4:u8]v.VecTake(2)
[1:u8, 2:u8]v
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecTake(3)
[1:u8, 2:u8, 3:u8]v
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecTake(4)
[1:u8, 2:u8, 3:u8, 4:u8]v
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecTake(0)
[]v:Vec[u8, 0]

Warning

If k is greater than n, the extra elements will be undefined.

> [1:u8, 2:u8, 3:u8, 4:u8]v.VecTake(5)
[1:u8, 2:u8, 3:u8, 4:u8, undefined:u8]v
>
> // Taking 4 elements from a vector of length 2 (!!!)
> [1:u8, 2:u8, 3:u8, 4:u8, 5:u8]v.VecTake(2).VecTake(4)
[1:u8, 2:u8, undefined:u8, undefined:u8]v
> // Taking 4 directly would have been fine
> [1:u8, 2:u8, 3:u8, 4:u8, 5:u8]v.VecTake(4)
[1:u8, 2:u8, 3:u8, 4:u8]v

See also

VecDropRight, if it is easier to say how many elements to discard than to say how many to keep

VecTakeRight, for discarding elements from the beginning of a vector

VecDrop, for discarding elements from the beginning of a vector

VecTakeRight(v: Vec[T, n], k: I): Vec[T, k], where I is an unsigned integer type#

Returns the last k elements of vector v, discarding the rest.

> [1:u8, 2:u8, 3:u8, 4:u8]v.VecTakeRight(2)
[3:u8, 4:u8]v
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecTakeRight(3)
[2:u8, 3:u8, 4:u8]v
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecTakeRight(4)
[1:u8, 2:u8, 3:u8, 4:u8]v
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecTakeRight(0)
[]v:Vec[u8, 0]

Warning

If k is greater than n, the extra elements will be undefined.

> [1:u8, 2:u8, 3:u8, 4:u8]v.VecTakeRight(5)
[undefined:u8, 1:u8, 2:u8, 3:u8, 4:u8]v
>
> // Taking 4 elements from a vector of length 2 (!!!)
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecTakeRight(2).VecTakeRight(4)
[undefined:u8, undefined:u8, 3:u8, 4:u8]v
> // Taking 4 elements directly would have been fine
> [1:u8, 2:u8, 3:u8, 4:u8]v.VecTakeRight(4)
[1:u8, 2:u8, 3:u8, 4:u8]v
